# SoundBoard Pro v20 - README

Premiere Composer-এর 500 SFX লিমিটে বিরক্ত হয়ে নিজেই বানিয়ে ফেললাম **SoundBoard Pro v20**!

আমি যখন Premiere Composer ইউজ করা শুরু করলাম, দেখলাম ফ্রি ভার্সনে মাত্র ৫০০ টা সাউন্ড ইফেক্ট শো করে। এর বেশি রাখা যায় না। রাগে-বিরক্ত হয়ে নিজের জন্য এই প্লাগইনটা বানিয়ে ফেলেছি। এখানে ইচ্ছামতো যত খুশি SFX ফাইল রাখতে পারবেন, কোনো লিমিট নেই।

---

### 🚀 নতুন ভার্সনের ফিচারসমূহ (v20):

* Unlimited SFX: যত খুশি সাউন্ড ফাইল রাখতে পারবেন, কোনো ৫০০ লিমিট নেই।
* VS Code Style Folder Tree: বাম পাশে সব ফোল্ডার সুন্দর Tree ভিউ-তে দেখা যাবে এবং কোনো ফোল্ডারে কয়টা ফাইল আছে সেটাও লাইভ কাউন্ট শো করবে। রেসপনসিভ স্প্লিটার টেনে ফোল্ডার বার ছোট-বড় করা যায়।
* One-Click Instant ADD: ১ ক্লিকেই প্রিমিয়ার প্রোর টাইমলাইনে নিখুঁতভাবে সাউন্ড যুক্ত হয়ে যাবে।
* Dynamic Track Space Allocation (No Overlap): টাইমলাইনে সাউন্ড বসানোর সময় প্লে-হেডের পজিশনে অন্য কোনো সাউন্ড থাকলে তা ওভারল্যাপ না করে অটোমেটিক পরবর্তী ফাঁকা অডিও ট্র্যাকে সাউন্ড প্লেস হয়ে যাবে (আগের কোনো সাউন্ড মুছে যাবে না)।
* Real Waveform & Timecode Display: সাউন্ডের রিয়েল-টাইম Waveform Preview, প্লে-হেড টেনে নির্দিষ্ট পয়েন্টে যাওয়ার সুবিধা (Seek) এবং মিলি-সেকেন্ডসহ অ্যাকুরেট টাইমকোড ডিসপ্লে।
* Global Instant Search: লাইব্রেরির সব ফোল্ডারের হাজার হাজার সাউন্ডের মধ্যে থেকে নাম লিখে সাথে সাথে কাস্টম সার্চ দিয়ে ইফেক্ট খুঁজে বের করার সুবিধা।
* Favorites & Custom Remark: পছন্দের ইফেক্ট আলাদা করে রাখা এবং Fav করা ফাইল নিজের মতো করে Rename / Remark করার অপশন (অরিজিনাল ফাইলে কোনো প্রভাব পড়বে না)।
* Integrated Trash Bin System: ভুলবশত প্লাগইন থেকে কোনো ফোল্ডার বা সাউন্ড রিমুভ করলেও তা হারিয়ে যাবে না, Trash Bin ট্যাব থেকে ১ ক্লিকে আবার Restore করা যাবে।
* Smart Keyboard Shortcuts: প্লাগইনে ফোকাস থাকা অবস্থায় কিবোর্ডের Spacebar চেপে প্লে/পজ এবং Left / Right Arrow চেপে মিলি-সেকেন্ড ফ্রেম ব্যাক ও ফরওয়ার্ড করার কাস্টম শর্টকাট।
* Powered by Rayhan3030

### 🛠️ কিভাবে ইন্সটল করবেন:

Step 1: Zip ফাইলটা Extract করুন। ভেতরে ৩টি ফাইল/ফোল্ডার পাবেন:

* com.rayhan.soundboardpro (ফোল্ডার)
* Enable Debug PR.bat (ফাইল)
* Read Me - Amare Poren.txt (ফাইল)

Step 2: প্রথমে Enable Debug PR.bat ফাইলটাতে Right-Click করে Run as administrator দিয়ে ওপেন করুন, তারপর ডায়ালগ আসলে Continue করে ক্লোজ করে দিন। এটি Premiere Pro-কে Debug Mode-এ নিয়ে যাবে যাতে Custom প্লাগইন নিখুঁতভাবে রান হতে পারে।

Step 3: এখন com.rayhan.soundboardpro ফোল্ডারটা কপি করে আপনার Premiere Pro-এর ইন্সটলেশন পাথের ভেতরে পেস্ট করুন:

`...\Adobe Premiere Pro [YOUR_VERSION]\CEP\extensions\`

(যদি CEP বা extensions ফোল্ডার না থাকে, তবে নিজে একই নামে বানিয়ে পেস্ট করুন)

Example Path:
`C:\Program Files\Adobe\Adobe Premiere Pro 2025\CEP\extensions\`

অথবা

`D:\Adobe\Premiere.Pro.2025\Installations\Adobe Premiere Pro 2025\CEP\extensions\`

Step 4: Premiere Pro বন্ধ থাকলে ওপেন করুন, আর ওপেন থাকলে Restart দিন।

Step 5: Premiere Pro-তে গিয়ে Window > Extensions > SoundBoard Pro এ ক্লিক করলেই প্লাগইন পেয়ে যাবেন।

### 🎮 কিভাবে ইউজ করবেন:

1. প্লাগইন ওপেন হলে উপরে কর্নারে Add Main Folder বাটনে ক্লিক করুন।
2. আপনার SFX-এর Main ফোল্ডারটা সিলেক্ট করে দিন (যেমন - D:\SFX বা Woosh, Splash, Transition যেখানে রেখেছেন)।
3. ব্যাস! বাম পাশে VS Code স্টাইলে সব ফোল্ডার Tree আকারে চলে আসবে।
4. কোনো ফোল্ডারে ক্লিক করলে ডান পাশে ওই ফোল্ডারের সব সাউন্ড দেখাবে।
5. সাউন্ডের ওপর ক্লিক করলেই প্লে হবে এবং নিচে Waveform ও Timecode দেখাবে।
6. ভালো লাগলে ADD বাটনে ক্লিক করলেই মুহূর্তের মধ্যে Timeline-এ সাউন্ড এড হয়ে যাবে!

Note: এটি CC 2022 থেকে Premiere Pro 2026 পর্যন্ত যেকোনো ভার্সনে অনায়াসে কাজ করবে।
